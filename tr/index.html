01 — DENEYİM / Experience

Altı yıldır kimlik doğrulama ve bankacılık işindeyim.

SofttechYazılım Mühendisi, tam zamanlıEyl 2020 — günümüzİstanbul

%30 → %90

akışı yeniden tasarladıktan sonra doğrulama başarı oranı: yüz tanıma yeniden denemeleri ve bulanık (fuzzy) MRZ/OCR eşleştirme.

  1. Uzaktan müşteri edinimi ve eKYC için Java 21 / Spring Boot 3 mikroservisleri; bankacılık, sigorta ve fintech müşterileri kullanıyor.
  2. Çoklu GPU’lu Linux sunucularda GPU hızlandırmalı bir OCR servisi kurup stabil hale getirdim (CUDA, cuDNN, multiprocessing) ve Java servislerine bağladım.
  3. Canlı veritabanının SQL Server tablo bölümleme (partitioning) geçişine liderlik ediyorum.
  4. İzleme ve performans paneli için REST API’ler: sayfalamalı, JPA Criteria API ile dinamik filtrelenen ve PostgreSQL ile SQL Server arasında taşınabilir.
  5. Canlıya çıkışa kadar UAT ve müşteri süreçleri: gereksinim netleştirme, hata önceliklendirme, SQL migrasyon scriptleri, hata analizi raporları.
  6. JUnit, Mockito ve TestNG ile TDD; Jenkins, XL Release, Docker ve Kubernetes/Helm ile teslim; SBOM taramalarından çıkan CVE’lerin giderilmesi.

Softtech’te daha önce

Leasing ve faktoring, yatırım ve açık bankacılık ürünleri için backend servisleri: Java, Spring, REST, MSSQL, Elasticsearch/Kibana.
